# NextChat 好友专属版

七人校园工作台新增功能、密码环境变量、身份存储迁移及验证记录见 [CAMPUS_WORKSPACE.md](./CAMPUS_WORKSPACE.md)。

## Vercel 部署

将这个项目导入 Vercel，选择 Next.js 框架和 Node.js 22 或更新版本。
安装使用 `yarn install --frozen-lockfile`，构建使用 `yarn build`。
不要设置 `BUILD_MODE=export`：访问校验和模型转发需要 Serverless API。

在 Vercel 的环境变量中配置以下内容，保存后重新部署：

| 环境变量          | 用途                                                             |
| ----------------- | ---------------------------------------------------------------- |
| `OPENAI_API_KEY`  | 服务端模型密钥，必填；浏览器没有自定义密钥入口                   |
| `FRIEND_PROFILES` | 密码与专属称呼、欢迎语、徽章的 JSON 映射                         |
| `CODE`            | 兼容原来的逗号分隔密码，可与专属密码并用                         |
| `BASE_URL`        | 可选，由管理员设置的 OpenAI 兼容服务地址；默认使用 OpenAI        |
| `DEFAULT_MODEL`   | 可选，默认 `gpt-6.2-sol`；可改为上游支持的准确模型 ID            |
| `CUSTOM_MODELS`   | 可选，沿用 NextChat 模型列表配置；此版本统一使用 OpenAI 兼容接口 |
| `VISION_MODELS`   | 可选，自定义模型的图片能力标记，沿用 NextChat 格式               |

`FRIEND_PROFILES` 示例（示例密码请替换）：

```json
{
  "replace-with-wang-password": {
    "name": "老王",
    "greeting": "老王专属通道已开启，随便造",
    "badge": "VIP 体验官"
  },
  "replace-with-li-password": {
    "name": "小李",
    "greeting": "欢迎回来，今天想探索什么？",
    "badge": "灵感合伙人"
  }
}
```

这是服务端变量，不要使用 `NEXT_PUBLIC_` 前缀。Vercel 输入框中直接粘贴 JSON，不要额外包一层引号。
本地开发可参考 `.env.template`，把配置放进忽略提交的 `.env.local`。

### 默认模型

2026-11-18：默认模型升级为 `gpt-6.2-sol`。本仓库的 `vercel.json` 同时将构建期与运行期的 `DEFAULT_MODEL` 设为此 ID，并在部署时已核实的 `CUSTOM_MODELS` 清单中加入 `+gpt-6.2-sol=GPT-6.2 Sol`，保留原有四个可选模型。这里仅存非敏感的模型设置，密钥和用户密码仍由 Vercel 管理。新会话与智能浓缩、连通性检查共用默认模型常量。浏览器和服务端会移除 GPT-6.2 不支持的 `temperature`、`top_p`；服务端同时移除旧客户端传来的 `logprobs`、`top_logprobs`。四档思考强度继续使用 `low` / `medium` / `high` / `xhigh`。[官方迁移说明](https://developers.openai.com/api/docs/guides/latest-model#migration-quickstart)

本版本按要求预设 `gpt-6.2-sol`，并内置 GPT-6 系列对话模型的图片输入识别规则（包括次版本和快照名称）。实际模型服务与访问权限由部署配置决定。若上游使用其他名称，请设置 `DEFAULT_MODEL`，必要时在 `CUSTOM_MODELS` 中加入 `+准确名称@OpenAI`；不符合内置命名规则的视觉模型别名可通过 `VISION_MODELS` 补充。

最终校园版在登录验证后，将七人的新会话默认模型固定为 `gpt-6.2-sol`；设置页只读显示此默认值。会话内仍可单独切换白名单允许的模型，历史会话不会被批量改写。四档思考强度只调整当前模型的 reasoning effort，极限档回退也不切换模型。

上游模型清单缺少默认模型时仍保留该选择，不会自动换成其他模型；请求不受支持时显示上游错误。`CUSTOM_MODELS` 的显式禁用规则仍然有效。

`CODE` 密码进入时展示通用欢迎资料；同一个密码同时存在于两处时采用专属资料。
未配置这两项时仍要求登录，四个新账号使用内置 SHA-256 密码哈希；原三人沿用已有配置。同名环境变量配置会禁用该用户的内置密码。配置了不合法的 JSON、缺失必需字段等情况则拒绝访问。

## 数据与访问方式

- `/api/auth/verify` 只接受 JSON POST `{"code":"当前密码"}`，成功只返回当前用户的 `name`、`greeting`、`badge`、`major`、`identityId`，不返回密码表或密码哈希。
- 浏览器只保存当前密码和当前资料，每次重新打开时再次向服务端验证。每条模型 API 请求仍独立校验密码，修改浏览器资料不会授予权限。
- 管理员的模型密钥只用于服务端转发。旧版存储的自定义 API Key、URL、外部提供商配置不会生效。
- 对话、设置、草稿及资料库保存在浏览器中，并按验证后的身份分区。切换身份读取各自记录，不提供云端同步。升级前未分区的数据继续保留，可在“设置与数据”中备份或确认导入。浏览器使用者仍可通过开发者工具访问本机存储；这不等同于操作系统账户或加密隔离。
- 不使用外部数据库。通用任意地址代理、远端同步、云端分享、MCP 服务进程和插件执行已关闭。原有文本、图片、HTML 下载导出保留。
- 默认不新增基于内存的假限流。需要限流时可在部署平台配置防火墙规则，无需引入数据库。

## 附件与导出

- 添加按钮、输入区拖拽、粘贴图片共用同一处理流程，拖拽时显示高亮。
- 图片支持 PNG/JPEG/WebP/GIF，每条最多 8 张（含 PDF 转换的页面），需要支持视觉的模型。尺寸较大或发送数据超预算的图片由浏览器等比缩放到长边不超过 2048px，并编码为 WebP 或 JPEG。一次最多添加 8 个文件。
- 聊天文档每条最多 5 份，单份最多 100 MB。PDF 中的文字按页在浏览器提取。文字超出当前附件预算时，可按页码范围导入，或导入预算允许的前部文字。附件会注明导入范围或比例。扫描件或文字稀少的 PDF 仍可使用视觉模型读取前 5 页，或选定范围内的前 5 页。
- PDF 页面图片采用白底 JPEG，最长边不超过 2200 像素，单页 data URL 不超过 480 KiB；先调整 JPEG 质量，再按需要降低尺寸。图片位置不足时整份 PDF 不加入，不静默丢弃页面；可单独删除某页，也可移除整份 PDF，发送说明会同步更新。
- 完整请求（含历史文字和图片）发送前检查 UTF-8 字节数，超过 4 MiB 时提示减少附件/页面或新建对话；不自动删除历史图片。此上限为 [Vercel 函数的 4.5 MB 请求上限](https://vercel.com/docs/functions/limitations#request-body-size) 留出余量。
- TXT、MD、CSV 和代码文件优先按 UTF-8 严格解码，其次尝试 GBK，也可读取带 BOM 的 UTF-16。Excel 提取单元格文本，PPTX 按演示文稿顺序提取幻灯片文字。旧版二进制 `.ppt` 需另存为 `.pptx` 或 PDF。
- `.docx` 在浏览器提取段落和表格文字。`.doc` 可读取纯文本、Word XML、HTML、常见 RTF 和重命名的 DOCX。旧版 OLE 二进制 `.doc` 需另存为 `.docx` 或 PDF。
- 每条消息的附件文字合计上限为 1M 模型 500,000 字符、256k 档 150,000 字符、常规模型 50,000 字符。超长文档可确认后导入前部文字。原文件在本地解析，提取文字及处理后的图片随消息发送。
- PDF.js worker、中文字体映射及标准字体由构建脚本生成到本站 `public/pdfjs/`，不依赖第三方 CDN，也不上传 PDF 原文件。
- 设置中的 JSON 导出只包含对话，并将本地附件图片嵌入文件，不包含访问密码或模型密钥。聊天导出支持文本和图片。
- “清除本地数据”会二次确认，仅清除当前身份的会话、资料库、草稿和设置并退出登录；其他身份和旧版未分区记录保留。共享附件缓存不批量删除，以免破坏其他身份导入的图片。

## GPT-6 温度兼容修复（2026-11-14）

全局新对话默认 `temperature` 为 `1`。后端 OpenAI 转发会对 `gpt-6`、`gpt-6-*` 和 `gpt-6.*` 模型移除请求体中的 `temperature`，使用模型默认值；即使浏览器旧缓存仍发送 `0.5`，也会在服务端处理。其他模型的温度及请求中的其他字段保留。此规则不依赖 `CUSTOM_MODELS` 是否配置，模型访问限制仍会生效。

实现采用省略采样参数的兼容方式，参考 [官方 OpenAI 文档](https://developers.openai.com/api/docs/guides/deployment-checklist)。本次仅处理温度字段。
