同名用户存在 `FRIEND_PROFILES` 条目或非空 `FRIEND_PASSWORD_*` 时，该用户的内置密码失效；已有自定义映射继续生效。密码冲突映射到不同姓名时会拒绝访问，不会覆盖原身份。字段 `major` 可省略，已知姓名会自动补齐专业。所有已验证用户的欢迎标题统一为“你好 姓名”。即使未设置密码环境变量，内置账号也会要求登录，不开放匿名模型调用。

`IDENTITY_SECRET` 可选，未配置时使用代码中的固定值 `nextchat-campus-identity-v1`，不依赖 `OPENAI_API_KEY`、`FRIEND_PROFILES` 或 `CODE`。因此轮换上游 API Key 或增减其他账号不会改变当前用户的存储分区。已有显式 `IDENTITY_SECRET` 应保持原值；更改该值或当前用户密码仍会形成新分区，修改前先导出会话。身份存储键由服务端 HMAC 产生，不直接使用明文密码。固定后备值仅用于浏览器数据分区，不作为登录令牌签名密钥，也不提供本机加密或云端账号系统。

旧版本未分区的记录不会删除，也不会自动归给第一个登录的人。在“设置与数据”中可备份旧记录、确认导入自己的旧会话。清除数据只作用于当前身份，不删除其他身份及旧记录，也不批量删除共享图片缓存。

## 功能入口

- 欢迎区桌面采用三列紧凑布局，默认显示 6 张卡片；“全部模板”下将当前专业置顶并标记“本专业推荐”，可展开全部 14 个。点击具体专业筛选时显示该专业的全部卡片。普通模板只填入输入框，不自动发送；建筑图像精修卡片直接打开图片选择器，选图后进入画笔 / 蒙版画布。原四张灵感卡片保留。
- 添加文件、拖拽支持 PDF、Word、Excel、CSV、文本及原有代码格式。解析在浏览器中完成，Word 表格保留行列分隔。PDF.js 使用构建时复制到本站的版本匹配 worker / 字体资源。
- 完整助手回复下方提供 Word 导出。含表格 / CSV 时显示 Excel，含至少两个完整代码块时显示 ZIP。Word 支持 H1–H3、强调、列表、表格和代码；Excel 含表头样式、列宽和筛选；ZIP 保留安全的相对文件名。
- `html`、`svg`、`mermaid`、`echarts` 代码块提供“预览 / Preview”。桌面为可拖动宽度的右侧面板，手机为抽屉。刷新、PNG、SVG 和独立 HTML 导出在面板顶部。ECharts 使用 JSON 配置，不执行配置中的函数。
- “本会话资料库”最多保存 10 份文件。文字按约 800 字符 / 重叠 150 字符分块，BM25 每次检索前 4 个相关片段。PDF 保留真实页码；Word、Excel、文本按段落定位，不虚构分页。回复中的来源按钮打开本次检索时的原文快照。
- “音频转文字”支持最多 25MB 的 m4a、mp3、wav、webm。点击开始才上传；大文件在浏览器解码为单声道 WAV 小片段，逐段调用认证的 `/api/transcribe`，模型固定为 `whisper-1`。转写文本先放入输入框，用户可编辑后发送。
- “联网检索”默认关闭。开启后由认证的 `/api/search` 请求 Responses API 的 `web_search`；公开来源显示为链接。只有接口 / 工具 / 模型明确不支持时才退回 Chat Completions，并标注本次未联网；认证、配额、内容拒绝等错误不通过回退绕过。
- 上传图片后可选择“图片精修模式”。画笔、撤销、重置及三个建筑调整快捷词生成 PNG 透明蒙版；透明区域表示允许编辑。图片和蒙版尺寸匹配，在浏览器压缩到单次请求限制以内。原图与结果在助手消息内通过滑块比较，可下载结果并继续微调。

## 主题、快捷操作与思考强度

聊天页头部和侧栏的“外观”可选择浅色 / 深色 / 跟随系统，以及莫兰迪绿（默认）、极客深海蓝、赛博暗紫、暖纸护眼四套配色。每套都有独立的明暗色值。主题与思考强度保存在当前身份的 `localStorage` 分区；首次升级会继承原外观偏好，后续重载在 React 启动前应用配色，避免浅色闪烁。切换身份恢复各自偏好，清除当前身份数据也会删除这些设置。

输入区模型按钮旁新增四档控件：极速（low）、均衡（medium，默认）、深度（high）、极限（xhigh）。手机上收为同一行的选择按钮。每次验证身份后，新会话默认模型固定为 `gpt-6.1-sol`；设置页不提供全局默认模型改写。会话内仍可手动选择白名单允许的模型，已有历史会话保留。强度不会更换模型或引入限流。普通请求使用 `reasoning_effort`，联网请求使用 Responses 的 `reasoning.effort`。

上游以 HTTP 400 / 422 明确报告 `xhigh` 为不支持的 reasoning effort 时，仅重试一次 `high`，保持模型、消息和鉴权不变；认证、额度及其他错误不触发回退。用户选择仍保持极限档，本次回复记录实际使用的深度档，并提示回退。上游返回 `<think>`、`reasoning_content` 或 Responses 思考摘要时，回复内显示可折叠卡片、强度标记和浏览器观察到的耗时；不编造上游没有提供的推理内容。

`Ctrl+K` / `Cmd+K` 或“⌘ K”打开快捷命令，支持模糊搜索全部 14 个模板，以及切换明暗、联网检索、四档强度，打开本会话资料库 / 本地编码工具，导出当前对话 JSON。导出只包含当前会话及其附件，不包含访问密码或模型密钥。有历史内容时选择新模板会创建新会话，保留原记录。

在助手消息内选择一段文字，会出现“深入解释 / 学术润色 / 中英互译 / 制作为 Anki 卡片”浮动操作。它们把选中片段作为引用填入输入框，用户检查后再发送；制卡操作要求模型输出现有 Anki 导出器可识别的结构。

## 可编辑 PPT 与 Word 公式

请求演示提纲、slides 或小组 Pre 时，默认系统提示会要求同时给出可读正文和一个 `slides` JSON 块：

```slides
{"title":"课堂汇报","slides":[{"title":"研究问题","subtitle":"背景与目标","bullets":["关键问题","证据与方法"],"notes":"演讲时补充的说明","layout":"bullets"}]}
```

支持 `title` / `bullets` / `two-column` 布局，以及带标题、以 `---` 分页的 Markdown 提纲。普通文章中的分隔线不会直接当成幻灯片。回复下方展示可横向滚动的迷你预览，选择“学术简约白”或“深色科技风”后，点击“导出 PPT (.pptx)”生成真实的 16:9 PowerPoint 文件。标题、正文、形状和演讲备注均可编辑；长页自动拆分续页，正文不会被截图替代。

Word 导出支持 `$...$`、`$$...$$` 以及应用常用的 `\(...\)` / `\[...\]` 公式。KaTeX 生成 MathML，mathml2omml 转为原生 OMML，保留分式、上下标、求和、根式和矩阵；公式也可出现在列表及表格单元格中。对转换库输出的裸操作符补为合法数学文本节点，避免相邻项在 Word 导入时丢失。不支持的宏或异常公式保留为 `[公式：原表达式]` 文本；代码示例中的美元符号不会当成公式。

新增依赖为 PptxGenJS 4.0.1（自带 TypeScript 类型）、KaTeX 0.19.1、mathml2omml 0.5.0 和 @types/katex 0.16.8。PptxGenJS 的完整浏览器版本由 `prebuild` 复制到本站，点击导出才加载；不让其 Node 文件接口进入 Next.js 服务端构建。公式转换器和文档生成器也只在浏览器导出时加载。

## 手机安装与拍照

`public/manifest.json` 包含 standalone 显示模式、固定应用 ID、启动路径、SVG 图标、192 / 512 PNG maskable 图标，另有 180 PNG Apple 图标与 iOS Web App 元信息。手机通过浏览器“添加到主屏幕”安装；聊天仍需要联网访问模型。保留缩放能力，并适配安全区域。

手机输入栏的“拍照识题”使用 `accept="image/*" capture="environment"` 请求后置相机。照片进入原有附件预处理、大小检查和图片识别流程，也可继续精修；具体相机或文件选择界面由手机浏览器决定。服务工作线程更新不会强制刷新进行中的聊天，保留原图片缓存；不缓存模型、登录或健康检查响应。

## 专业工具（保留）

默认系统提示已加入全局格式约定：自由提问涉及分子结构、记忆卡、思维导图或科学计算时，模型应输出相应的 `smiles`、`anki`、`mindmap` 或含 numpy / matplotlib 的 `python` 代码块。不需要先点模板；最终输出仍取决于上游模型是否遵循提示，代码执行和图片编辑必须由实际工具完成后才能声称成功。

| 代码块 | 浏览器行为 |
| --- | --- |
| smiles / `<smiles>…</smiles>` | OpenChemLib 绘制 SVG 骨架并计算分子式、摩尔质量；可导出 SVG/PNG |
| anki | JSON `{name,cards:[{front,back}]}` 或 `Q:/A:` 问答，以 `---` 分隔；sql.js 生成 SQLite collection.anki2，JSZip 打包为 .apkg |

侧栏“本地编码工具”支持 Base64、Hex、URL、JWT 解码、XOR、MD5 和 SHA-256。JWT 仅解码，不做签名验证。全部输入在浏览器中处理。

发送前的轻量规则拦截部分明确的攻击载荷或生成请求；网安 / 计科模板附加授权防御与学术 CTF 背景。这不是完整内容审核，也不能保证账号不会受限。实际授权范围与上游规则仍适用。

## 边界与运行方式

所有大型解析、导出、分子计算、Anki SQLite 和 Python 均按需在客户端加载。预览 iframe 使用 `sandbox="allow-scripts"`，不允许同源访问；导出消息同时核对来源窗口、随机令牌和请求 ID。Python worker 没有主页面的本地存储身份，关闭 iframe 可终止运行。

HTML 的 PNG 导出通过静态布局快照重建，不把可执行 HTML 放入主页面；适合自包含的 HTML、内嵌 SVG 和 Canvas。外部图片需要先嵌入为 data URL，复杂 CSS 的还原取决于截图库支持。SVG 没有 viewBox 时，会根据明确的宽高补齐，避免手机预览裁切。

文件输入上限沿用单份 10MB（音频为 25MB）、文字单份 60,000 / 合计 80,000 字符等限制。资料库单份 PDF 最多 100 页；扫描 PDF 无可检索文字时提示改用聊天视觉上传，不假装完成 OCR。音频解码能力受浏览器格式支持和可用内存影响。首次 Python 下载需要访问 jsDelivr，其他工具运行资源由构建过程复制到本站。

新增接口只读取管理员配置的 BASE_URL / OPENAI_API_KEY，不接收客户端 API Key 或任意目标地址。请求体读取限制为 4 MiB。图片结果通过流式响应交付；主模型固定 `gpt-image-2.6-sunburst`，仅在模型不支持时采用 `IMAGE_EDIT_FALLBACK_MODEL`（默认 `gpt-image-2.5-flare`）。官方文档说明 `gpt-image-1` 已于 2026-10-23 停用，因此默认后备没有指向它。[图像编辑文档](https://developers.openai.com/api/reference/resources/images/methods/edit)

运行 `yarn install --frozen-lockfile` 后执行 `yarn build`。`prebuild` 准备本地 PDF 和工具资源；这些生成文件不提交到仓库。构建沿用项目 Next.js 14.1.1 / React 18，不升级原有服务端框架。

本地检查使用模拟上游服务，不代表真实账户拥有 Whisper、联网工具或 Image-2.6 权限。本轮未修改 Vercel 配置或部署线上。保留原三人的密码和现有上游配置即可启用四个新身份；`IDENTITY_SECRET` 可使用稳定的代码默认值。

### 计算和数据约定

- 拟合采用中心化、缩放后的二次正交化 QR 最小二乘，避免直接求解正规方程。结果展示完整双精度系数和归一化变量关系；“精确”指确定的本机数值计算，非符号代数或无限精度。指数与幂律以 `ln(Y)` 为拟合目标，所有模型的 R² 都在原始 Y 尺度计算；Y 无变异时 R² 未定义。不会自动删除异常值。空白、非数值和违反模型定义域的输入会被列明或拒绝，Excel 公式使用文件已保存的缓存值，不重新计算。
- 数据文件上限 10 MB，每工作表最多 10,000 条数据、64 列、20 个工作表；聊天附件文字仍受原有附件预算约束。表格每组展示 100 行，计算使用所有启用的有效数据。

- 合并按 ID 去重。内容相同的记录跳过；不同内容保留本机版本，创建稳定 ID 的导入副本。会话冲突时，导入笔记的来源指向对应副本；来源发生变化也会保留新的笔记副本。快捷指令名称冲突会附加“_导入”，同时保证 ID 不重复。再次导入相同包或相同冲突包不会继续增加副本。
